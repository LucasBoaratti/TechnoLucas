# ⌨️ TechnoLucas ⌨️

A TechnoLucas é um site de eletrônicos onde você pode registrar um equipamento eletrônico como SmartTVs, smartfones e notebooks, podendo atualizar ou excluir. Além disso, você também verá o histórico de movimentações dos principais produtos que você registrou, podendo atualizar o estoque com entradas ou saídas de produtos :0

# Instalação e uso

1. Clique no botão Code e copie a URL do projeto:

```bash
https://github.com/LucasBoaratti/TechnoLucas.git
```

2. Abra o Prompt de comando (ou PowerShell ou GitBash) em sua área de trabalho ou em documentos e realize o seguinte comando:

OBS: Certifique que o Git está instalado no seu computador. Caso não esteja, instale aqui: [Git](https://git-scm.com/downloads)

```bash 
git clone https://github.com/LucasBoaratti/TechnoLucas.git
```

3. Acesse a pasta do projeto:

```bash
cd .\TechnoLucas
```

4. Agora, entre no VSCode:

```bash
code .
```

5. Abra o terminal com CTRL + J ou CTRL + ' e acesse a pasta Sistema:

```bash
cd .\Sistema
```

6. Verifique se o python está instalado em seu PC e no VSCode;

7. Se não tiver instalado na máquina, faça o download [aqui](https://www.python.org/);

8. Instale o python no VSCode também (se já tiver instalado, ignore esse passo);

9. Após a instalação, acesse a pasta BackEnd:

```bash
cd .\BackEnd
```

10. Agora, instale a pasta .venv (ambiente virtual do python):

```bash
py -m venv .venv
```

11. Ative o ambiente virtual:

```bash
.\.venv\Scritps\activate
```

12. Instale as dependências:

```bash
pip install -r requirements.txt
```

13. Rode o servidor:

```bash
py .\manage.py runserver
```

14. O servidor pode ser acessado pela URL:

```bash
http://127.0.0.1:8000/
```

15. Agora, abra outro terminal, clicando em +;

16. Verifique se o node está instalado em seu PC;

17. Se não tiver, faça o download [aqui](https://nodejs.org/en/download);

18. Após a instalação, instale a pasta node_modules:

```bash
npm i
```

19. Rode o servidor:

```bash
npm run dev
```

20. O servidor pode ser acessado pela URL:

```bash
http://localhost:5173/
```

#### OBS: Acesse a URL gerada pelo node (http://localhost:5173/) para ter a experiência real de um usuário.

E pronto! Agora você pode se divertir com o projeto! :D
